# Экологические показатели и расчёт выбросов CO2

> Учебный документ: вымышленные правила для демонстрационного проекта.

## Расчётные нормы
Для оценки рейса используются усреднённые значения: расход топлива 32 литра на 100 километров, средняя скорость 70 км/ч, выбросы 2,68 кг CO2 на литр дизельного топлива. Расстояние по дорогам принимается на 25% больше расстояния по прямой.

## Пример расчёта
Рейс длиной 1000 км требует около 320 литров топлива и создаёт около 858 кг CO2. Время в пути при средней скорости 70 км/ч составляет около 14,3 часа.

## Цели по снижению
Целевой показатель компании: снижение выбросов на тонну груза на 5% в год. Основные меры: консолидация недогруженных рейсов, выбор маршрутов без частых остановок, ночные выезды для избежания заторов.

## Отчётность
Выбросы CO2 по каждому рейсу сохраняются в системе и включаются в ежемесячный отчёт руководителю логистики.
