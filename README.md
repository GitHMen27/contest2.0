# WB Logistics Command Center

**WB Logistics Command Center** — демонстрационная платформа для мониторинга и управления логистической сетью Wildberries.

Проект объединяет интерактивную карту распределительных центров, цифровой двойник склада, AI-помощника и инструменты анализа логистических процессов.

## Сайт проекта

**Демонстрация:** [ВСТАВИТЬ ССЫЛКУ НА САЙТ]

Сайт доступен онлайн. Для знакомства с проектом не требуется установка дополнительных программ.


## Основные возможности

- **Карта логистической сети** — отображение распределительных центров, маршрутов и движения транспорта.
- **Цифровой двойник РЦ «Шушары»** — интерактивная 2D/3D-модель склада с зонами, сотрудниками, техникой и маршрутами.
- **AI-помощник** — поиск информации по логистическим регламентам с использованием RAG.
- **Центр инцидентов** — мониторинг проблем, задач и истории операций.
- **Симулятор сценариев** — моделирование перегрузок, нехватки персонала, поломок техники и задержек.
- **Экономика сети** — анализ демонстрационных расходов и сравнение распределительных центров.

## Как познакомиться с проектом

Рекомендуемый порядок просмотра:

1. Откройте главную страницу и изучите карту логистической сети.
2. Перейдите в РЦ «Шушары» и попробуйте цифровой двойник склада.
3. Проверьте работу AI-помощника, задав вопрос по регламентам.
4. Откройте симулятор и измените параметры одного из сценариев.
5. Изучите экономику сети и сравнение распределительных центров.

## Особенности демонстрационной версии

Проект демонстрирует концепцию единой системы управления логистической сетью.

Важно учитывать несколько ограничений:

- Цифровой двойник реализован для одного распределительного центра — «Шушары».
- Остальные пять РЦ отображаются на общей карте сети.
- Перемещения сотрудников и техники моделируются программно.
- Инциденты, задачи и изменения склада хранятся в локальном состоянии браузера.
- Симулятор и экономическая модель используют демонстрационные данные, а не реальные показатели Wildberries.

Интерфейс поддерживает работу с подключённым backend и резервный демонстрационный режим.
